01 About

I'm a Computer Engineering Technology (Computing Science) student at Algonquin College in Ottawa, on the Dean's List, graduating in 2027. I like knowing how things work all the way down, and fixing them when they don't.

Outside class that turned into a home lab: a Linux server running about thirty services, a voice assistant I trained myself, and a pile of tools for my own machines. Most of my IT experience comes from helping people one problem at a time, first as a freelancer and most recently as an IT support co-op.

I was born in New Delhi in 2006, moved to Canada in 2013 and became a citizen in 2018. I grew up in Brockville, Ontario.

Home lab · Self-hosted

Phrolova, my Linux home server

An Ubuntu server that runs about thirty Docker services: media (Jellyfin, Navidrome), photos (Immich), Home Assistant, an offline copy of Wikipedia, a private search engine, game servers and more, across an SSD and two hard drives.

  • Bash monitoring that sends Discord alerts when a service goes down or the CPU overheats.
  • Samba file sharing and Tailscale for secure remote access, with no ports opened.
  • Moved a BeamMP game server from Windows to Linux, getting past CGNAT with Tailscale.
  • A dashboard and a wall tablet that show every container, with one-tap restarts.

Voice assistant · Home Assistant

Fairy, a voice assistant I trained myself

A self-hosted voice assistant with its own personality. It listens through the server's built-in microphones and controls my lights, music, laptop and server.

  • Trained a custom "Hey Fairy" wake word with openWakeWord on my laptop's GPU (30,000 synthetic clips).
  • Thinks with a local model (Qwen3 on Ollama) when my laptop is on, and falls back to the cloud otherwise.
  • Tools for server health, container restarts (it asks first), offline Wikipedia, web search and laptop control.
  • Patched the satellite so it listens again after asking a question.
